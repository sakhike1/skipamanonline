Design Studio garment photos
============================

The studio recolours plain BLACK garment photos in the browser, so one photo covers every colour.
Good photos: front view, plain black garment, white or very light plain background, no logo or print,
no model, sharp, at least 800 px wide.

Files the studio already uses:
  acdaaaf3...jpg   plain black tee (front)
  b095e74f...jpg   plain black hoodie (front)
  16bb0001...jpg   plain black cap (front)
  model-tee.jpg    model wearing a plain black tee (for the "On a person" view)

Add these names and the garment appears in the studio on its own (no code change needed):
  jersey.jpg       school jersey / sports shirt (front)
  blazer.jpg       school blazer (front)
  beanie.jpg       beanie (front)
  bucket-hat.jpg   bucket / sun hat (front)

Optional back views (turn on the real Back view for that garment):
  tee-back.jpg, hoodie-back.jpg, jersey-back.jpg, blazer-back.jpg
(same rules: plain black, back view, same framing as the front photo)

After adding a photo, tell me and I will fine-tune where the print area sits on it.
